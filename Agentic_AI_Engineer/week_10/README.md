This week is essentially the integration/deployment week. Since we already have the individual agents and the orchestrator, the goal is to now make the whole system usable through WhatsApp from beginning to end. 

This deliverable encompasses this idea:
- "Can a user send a normal message in WhatsApp, have my orchestrator figure out what they want, route it to the correct agent(s), retrieve the data, format the answer, and send the result back to WhatsApp?"
